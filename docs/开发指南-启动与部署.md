# 开发指南：启动与部署

> 本文档详细说明如何启动项目、访问各服务、执行框架命令，以及日常开发和部署的完整流程。项目采用 Docker 全容器化，**无需在本地安装 PHP / Node / MySQL**。

---

## 1. 环境要求

唯一需要的是 **Docker Desktop**（含 Docker Compose）。请确保：

```bash
docker --version      # 需要 20.10+
docker compose version # 需要 2.0+
```

> 本项目在 Windows 上开发验证，Linux / macOS 同样适用。

---

## 2. 容器架构

项目由以下容器组成（定义在根目录 `docker-compose.yml`）：

| 容器 | 镜像 | 端口 | 用途 |
|------|------|------|------|
| mwp-php | 自建（php-dev.Dockerfile） | 8001 | PHP 应用（内置服务器） |
| mwp-mysql | mysql:8.0.36 | 3306 | 数据库 |
| mwp-redis | redis:7.2-alpine | 6379 | 缓存 |
| mwp-rabbitmq | rabbitmq:3.13 | 5672/15672 | 消息队列 |
| mwp-minio | minio/minio | 9000/9001 | 对象存储 |
| mwp-elasticsearch | elasticsearch:7.17 | 9200 | 搜索引擎（预留，默认不启动） |

## 3. 首次启动（从零开始）

### 第 1 步：启动所有服务

```bash
docker compose up -d
```

首次执行会**自动构建 PHP 镜像**（下载基础镜像 + 编译 PHP 扩展），需要几分钟。之后启动就是秒级。

### 第 2 步：等待服务就绪

```bash
docker compose ps
```

等到所有服务状态显示 `healthy`（健康）：

```
NAME            STATUS
mwp-php         Up (healthy)
mwp-mysql       Up (healthy)
mwp-redis       Up (healthy)
mwp-rabbitmq    Up (healthy)
mwp-minio       Up (healthy)
```

### 第 3 步：导入数据库（仅首次）

```bash
docker exec -i mwp-mysql mysql -uroot -pdev123456 \
  --default-character-set=utf8mb4 my_web_project < db/sql/module1_user.sql
```

> 注意 `--default-character-set=utf8mb4` 必须带，否则中文会乱码。

### 第 4 步：验证

```bash
# 健康检查
curl http://localhost:8001/ping
# 期望输出：{"code":0,"message":"pong","data":[]}

# 测试登录
curl -X POST http://localhost:8001/api/v1/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "identifier=admin&password=Admin@123456"
```

## 5. 日常开发命令

### 5.1 服务管理

```bash
docker compose ps                        # 查看状态
docker compose logs -f php               # 实时查看 PHP 日志
docker compose logs -f mysql             # 查看 MySQL 日志
docker compose restart php               # 重启 PHP
docker compose down                      # 停止并移除所有容器
docker compose up -d                     # 重新启动
```

### 5.2 代码改动

**后端 PHP 代码**：改完即生效（volume 挂载），无需重启。若改了路由或配置文件，可能需重启 PHP：

```bash
docker compose restart php
```

**数据库结构**：改了 `db/sql/` 里的 SQL，需重新导入或手动执行。

### 5.3 查看容器内部

```bash
# 进入 PHP 容器
docker compose exec php sh

# 进入 MySQL 客户端
docker compose exec mysql mysql -uroot -pdev123456 my_web_project
```

## 6. 框架命令（ThinkPHP CLI）

通过容器执行 ThinkPHP 命令行：

```bash
# 查看版本
docker compose exec php php think version

# 查看所有可用命令
docker compose exec php php think list

# 清缓存
docker compose exec php php think clear

# 生成随机密钥（生产环境 JWT 用）
docker compose exec php php -r "echo bin2hex(random_bytes(32));"
```

## 7. 前端开发流程

前端源码在 `frontend/`，构建产物输出到 `public/app/`。

### 7.1 修改前端代码后重新构建

由于本地无 Node，构建走 Docker：

```bash
# 在项目根目录执行（Windows Git Bash）
docker run --rm -v "$PWD":/app -w /app/frontend node:20-alpine \
  sh -c "node node_modules/vite/bin/vite.js build"
```

> 说明：`node_modules/.bin/vite` 的符号链接在 Windows 挂载卷上失效，所以用 `node node_modules/vite/bin/vite.js` 直接调用。

### 7.2 首次安装前端依赖

```bash
docker run --rm -v "$PWD":/app -w /app/frontend node:20-alpine \
  sh -c "npm install"
```

### 7.3 前端目录结构

```
frontend/src/
├── api/          # 后端 API 封装（axios 拦截器 + 无感刷新）
├── stores/       # Pinia 状态管理
├── router/       # Vue Router（路由守卫 + 角色检查）
├── layouts/      # 布局组件
└── views/        # 页面组件
```

## 8. 生产部署（预留，当前未使用）

生产环境使用 `docker/docker-compose.prod.yml`，与开发环境的区别：

| 差异 | 开发环境 | 生产环境 |
|------|---------|---------|
| Web 服务器 | PHP 内置服务器 | Nginx + PHP-FPM |
| 编排文件 | docker-compose.yml（根目录） | docker/docker-compose.prod.yml |
| 管理端口 | 全部对外开放 | 仅限本机（127.0.0.1） |
| 环境变量 | 默认值 | 强制注入（`:?` 语法） |

**部署步骤**（将来购买云服务器后）：

```bash
# 1. 服务器安装 Docker + Compose
# 2. 克隆代码
git clone <仓库地址>
# 3. 设置真实密码（环境变量）
export MYSQL_ROOT_PASSWORD=xxx
export REDIS_PASSWORD=xxx
export JWT_SECRET=xxx
# 4. 构建并启动
docker compose -f docker/docker-compose.prod.yml up -d --build
# 5. 导入数据库
docker exec -i mwp-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" \
  --default-character-set=utf8mb4 my_web_project < db/sql/module1_user.sql
```

## 9. 故障排查

### 9.1 端口被占用

```bash
# 查看谁占了 8001 端口
docker ps
netstat -ano | findstr 8001
# 停掉冲突容器或改 docker-compose.yml 的端口映射
```

### 9.2 PHP 容器启动失败

```bash
docker compose logs php
# 常见原因：镜像构建失败（网络问题），重试：
docker compose build php
```

### 9.3 数据库连接失败

检查 `.env` 里的数据库配置：

```ini
[database]
hostname = mysql     # ← 必须是 mysql（容器网络内的服务名，不是 127.0.0.1）
password = dev123456
```

### 9.4 中文乱码

数据库导入时忘加 `--default-character-set=utf8mb4`。重新导入：

```bash
docker exec mwp-mysql mysql -uroot -pdev123456 my_web_project \
  -e "DROP TABLE IF EXISTS user_role, role_permission, permission, role, verification_code, refresh_token, user;"
docker exec -i mwp-mysql mysql -uroot -pdev123456 \
  --default-character-set=utf8mb4 my_web_project < db/sql/module1_user.sql
```

### 9.5 接口限流 429

登录/发送验证码太频繁触发了限流。清空限流缓存：

```bash
# 清理 runtime 下的 cache 目录
find runtime -type d -name cache -exec rm -rf {} +
```

### 9.6 前端页面 404

说明前端还没构建。执行前端构建命令（见第 7 节）。
