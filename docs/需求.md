# 项目需求文档

> 最后更新：2026-08-02

## 项目定位

一个企业级 Web 平台，通过实现多个功能模块来实践和提升后端/前端开发技术。**重点是技术深度而非业务内容本身。**

- **后端**：ThinkPHP 6 + PHP 8.1
- **前端**：Vue 3 + Vite
- **数据库**：MySQL

---

## 四大功能模块（按实现优先级排序）

### 1. 用户系统（注册 / 登录）

| 功能点 | 方案 | 说明 |
|--------|------|------|
| JWT 鉴权 | Access Token（15min）+ Refresh Token（7天） | 双 Token 机制 |
| 无感刷新 | ✅ 前端拦截器自动刷新 | 用户无感知 |
| 注册验证 | 邮箱验证码 + 手机验证码 | 双通道验证 |
| 权限模型 | 渐进式 RBAC | 先做 普通用户/管理员，架构预留角色-权限扩展 |
| 第三方登录 | 暂不支持 | 后续按需添加 |
| 密码安全 | bcrypt 哈希 + 登录失败锁定 | 5次失败锁定15分钟 |
| 密码重置 | 忘记密码 → 验证码 → 重置 | ✅ 已完成（防用户枚举） |

**技术点清单：**
- JWT 生成/校验/刷新（`lcobucci/jwt` 或 `firebase/php-jwt`）
- 中间件拦截鉴权
- 验证码发送（邮件 + 短信）
- RBAC 权限表设计（用户 → 角色 → 权限）
- 接口限流（防暴力登录）

### 2. AI 对话

对接 **DeepSeek** 大模型（API 兼容 OpenAI 格式，接入成本低）。

| 功能点 | 方案 | 说明 |
|--------|------|------|
| AI 服务商 | DeepSeek | 兼容 OpenAI API 格式，支持流式输出 |
| 计费模式 | 混合模式 | 按量计费（余额充值）+ 订阅套餐 |
| 流式输出 | ✅ SSE（Server-Sent Events） | 逐字流式返回，提升体验 |
| 对话历史 | ✅ | 持久化存储，支持多轮上下文 |
| 多会话管理 | ✅ | 用户可创建/切换/删除多个会话 |
| 角色/提示词预设 | ✅ | 自定义 System Prompt，定制 AI 角色 |
| 消耗明细账单 | ✅ | 记录每次调用的 Token 消耗和费用 |

**技术点清单：**
- DeepSeek API 对接（OpenAI 兼容 SDK）
- SSE 流式响应（ThinkPHP 长连接输出）
- 统一 AI 服务抽象层（方便未来切换服务商）
- 计费系统（余额扣减 + 订阅周期管理）
- 充值订单系统（对接支付）
- Token 消耗追踪与账单

### 3. 资源上传与下载

**「云端转存 + 个人网盘」合二为一**，存储层采用 **MinIO 自建对象存储**。

| 功能点 | 方案 | 说明 |
|--------|------|------|
| 核心模式 | 云端转存 + 个人网盘 | URL 远程下载 + 本地上传 + 分享下载 |
| 存储后端 | MinIO 自建 | Docker 部署，完全兼容 S3 API，方便未来迁移云 OSS |
| 分片上传 | ✅ | 大文件分片，支持断点续传 |
| 秒传检测 | ✅ | 文件 SHA256 去重，相同文件无需重复上传 |
| 异步处理 | ✅ | 上传后通过消息队列异步转码/压缩/生成缩略图 |
| 下载限速/防盗链 | ✅ | 签名 URL 临时授权，Referer 白名单，速率限制 |

**技术点清单：**
- MinIO Docker 部署与 S3 SDK 对接
- 大文件分片上传（前端分片 + 后端合并）
- 文件 hash 秒传（上传前先校验 SHA256）
- 异步任务（消息队列处理转码/压缩）
- 签名 URL 防盗链（时效性下载链接）
- WebSocket/SSE 推送上传进度

### 4. 三方功能

**「商城系统 + 内容社区」双场景**，通过不同业务实践多种企业级技术。

| 功能点 | 方案 | 说明 |
|--------|------|------|
| 业务场景 | 商城 + 内容社区 | 商品/订单/支付 + 文章/评论/互动 |
| 消息队列 | RabbitMQ | 企业级消息中间件，支持 ACK/死信/延迟队列 |
| 支付 | 模拟支付 | 专注订单状态机 + 消息队列技术实现 |
| 全文搜索 | ElasticSearch | 商品搜索 + 文章搜索 |
| 缓存策略 | Redis | 热点缓存、穿透/击穿/雪崩防护 |
| 定时任务 | Crontab | 订单超时取消、账单周期结算 |
| API 保护 | 限流 + 熔断降级 | 高并发防护策略 |

**技术点清单：**
- RabbitMQ 安装配置与 think-queue 集成
- 订单状态机设计（待支付 → 已支付 → 已发货 → 已完成 → 已取消）
- 延迟队列（订单超时自动取消）
- ElasticSearch 中文分词搜索
- Redis 缓存策略（Cache Aside、布隆过滤器防穿透）
- 定时任务（ThinkPHP 命令行模式 + Crontab）
- API 限流（令牌桶/滑动窗口）+ 熔断降级（Circuit Breaker）
